# Darshan Bagi Portfolio v2

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript for GitHub Pages. Includes an animated marquee, project carousel controls, project-detail modal, responsive navigation, scroll reveals, work metrics and contact links.

## Publish to the existing GitHub Pages site
1. Download and unzip this folder.
2. Open the `darshanbagi-portfolio` repository on GitHub.
3. Upload/replace `index.html`, `style.css`, `script.js`, and the complete `assets` folder in the repository root.
4. Commit the changes to `main`.
5. Wait for GitHub Pages to deploy, then visit `https://darshanbagi.com`.

Keep the asset filenames and folder structure unchanged unless you also update the image paths in `index.html`.

## Before publishing
- Confirm that you are happy publishing your email address and external profile links.
- Review all CV metrics and only keep numbers you can substantiate.
- The dashboard screenshot is used as a visual reporting sample. Make sure it contains no confidential client or account information before publishing.
- The Annotsav artwork and Scratchpad research cover are designed mock-ups, not original client deliverables. Replace them with approved original assets if available.
- The site links to the public Instagram pages and LinkedIn profile; it does not embed Instagram's live feed.
